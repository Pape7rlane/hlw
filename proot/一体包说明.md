# 一体包（定稿）

**成品**：一个 285 MB APK，内置服务端 + GM 面板 + 满级存档。

## 使用

1. 安装 APK
2. 打开游戏
3. 标题页点「切换服」→ 选 LocalServer → 确定（首次需要，之后记住）
4. 进主城：90 级 / VIP15 / 102 关全解锁
5. 画面左侧 **GM** 按钮：角色切换、自定义属性、重放剧情、恢复全通关

## 实现

| 组件 | 说明 |
|---|---|
| 服务端 | 纯 Java（`javasrv/src/com/hlw/srv`），跑在游戏进程内 |
| 端口 | HTTP 8080（服务器列表/会话/cb.php）、TCP 9000（握手/进关卡） |
| 注入点 | `com/ada/ane/sdk/EntryActivity.onCreate` → `Gm.start(activity)` |
| 存档 | `assets/hlw/player_ud.json`，首启复制到 files 目录 |
| 广告 | `adaAlarmReceiver.onReceive/showNotification`、`adaAlertDialog.call` 已置空 |
| 签名 | 我们的 keystore（换签名会失效，可用于防二次打包） |

## 为什么不用 Python

Chaquopy 与 AIR 同进程会原生崩溃（mutex / SIGSEGV），改纯 Java 后彻底规避，包体也小 10 MB。
