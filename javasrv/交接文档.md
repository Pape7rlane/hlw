**关键发现**：`hlxd.swf` 的文件头是 `ZWS`，不是加密，**是 LZMA 压缩**。

```
ZWS(3) + version(1) + 原始总长(4) + 压缩数据长(4) + LZMA props(5, = 5d 00 00 20 00) + LZMA raw 数据
                 = 20356307                              dict=2MB, lc=3, lp=0, pb=2
```

解压脚本（已可用）：

```python
import lzma, struct
d = open('assets/hlxd.swf','rb').read()
filters=[{"id":lzma.FILTER_LZMA1,"dict_size":0x200000,"lc":3,"lp":0,"pb":2}]
body = lzma.LZMADecompressor(format=lzma.FORMAT_RAW, filters=filters).decompress(d[17:])
# body 长度 20356299，前面补 8 字节头即为标准 SWF
swf = b'FWS' + bytes([0x22]) + struct.pack('<I', 8+len(body)) + body
```

解出的 `game.swf` 是标准 SWF（version 34, 1280x800 @15fps），**FFDec 可直接反编译**。

### 3. 网络协议（已完全逆向）

**包格式**（大端）：

```
[byte 0x07][int32 总长含11字节头][byte msgVersion][byte 0][int16 id][int16 type][body]
```

**加密**：XOR 循环密钥，密钥由服务端下发（`GCCryptKey` type=116）。

> ⚠️ **2026-11-24 20:12 更正（原文档此条是错的）**：
> 「不下发密钥就走明文」是误判。反编译确认 `StreamManager.OnCryptKey()` 里有：
> ```as
> SendMessage(new CGCryptKey());          // 回 115（此时 cryptKey 还是 null，明文发）
> cryptKey = param1.message as GCCryptKey;
> _status = 2;
> dispatchEvent(new StreamEvent("ready",null));   // ★ "ready" 唯一来源
> ```
> 而 `StreamWrapper.OnStreamReady()`（唯一发 `CGVersion(128)` 的地方）是挂在 `"ready"` 上的。
> **所以不下发 116 → 客户端永远停在 STATUS_CONNECTED：不报错、不重连，只每 20 秒发心跳。**
>
> 正确做法：连接后立刻下发 116，密钥给 4 字节全 0（XOR 恒等，协议仍是明文，
> 但客户端 `cryptKey` 非空，握手继续）。实现见 `mock/server.py: build_crypt_key()`。

**握手流程**：

```
TCP 连接
  → C→S: CGVersion(128)     带 version="1.3.6"
  → S→C: GCVersion(129)     body = int32(0)
  → C→S: CGLoginAccount(117) account/password/session/loginType
  → S→C: GCLoginAccount(118) body = int32(0)
  → C→S: CGLoginPlayer(119)
  → S→C: GCLoginPlayer(120)  body = int32(0)
  → C→S: CSInitPlayer(608)
```

**通用规则**：请求 type N → 响应 type N+1，body 至少 4 字节 int32 result(0)。

### 优先级 1：进关卡（最影响可玩性）

客户端流程：`CmdMap` → `CSLockLevel` → 等服务端 `SCLockLevel(copyID, onlineNum, param)` →

| type | 类 | 服务端要回的字段 |
|---|---|---|
| 锁关卡 | `CSLockLevel`/`SCLockLevel` | result(int) copyID(int) onlineNum(int) param(string) |
| 进关卡 | `CSEnterLevel`/`SCEnterLevel` | result(int) |
| 战斗包 | `WC*` | 见 `stream/message/WC*.as`，逐类对齐 |

## 七、踩过的坑（省时间用）

0. **`type=1` 是心跳不是解析错误**；握手必须先下发 `GCCryptKey(116)`，否则客户端静默卡在「已连接」（见第三节）
0b. 主动推策略文件会让客户端 `ProcessMessage` 见到非 `0x07` 首字节就**整段清空缓冲区**，
    同一次 recv 里的真包会一起丢 → 推送与业务包之间留 0.5s 间隔，或干脆等 `<policy-file-request/>`
0c. **`gearsystem` / `extatv` 包内有正版，绝对不要用 overrideCfgs 覆盖**（会写坏 Local Store 且优先于包内读取）
0d. `extatvBtnList` 包内没有 → 必须下发 `{"ver":1,"debugAs":null}`，否则 `EquipSystem.show()` #1009 中断
0e. `userDGroup["6"]["story"]["g0_i0"]["bastJudge"]` 必须给真值，否则走状态机分支永久卡 40%
1. `ZWS` 不是加密是 LZMA —— 别再找解密算法
2. `server0` 字段必须带 `http://` 前缀，客户端直接拼接
3. `serverid0` 必须是**数组**，给字符串会抛 `TypeError` 且被 try/catch 静默吞掉
4. `cb.php` 是相对路径 → `app:/cb.php`，靠 `_loc2_ + url` 拼接域名前缀
5. `.pack` 资源文件必须 **zlib 压缩**，客户端会 `uncompress("zlib")`
6. `newuser:["1"]` 会触发 `startFakeGame()` 走本地假游戏，永远不连服务器 → 必须 `["0"]`
7. `EquipSystem.show()` 开头 `if(showing) return` —— 崩一次就永久锁死，**每次测试必须杀进程重开**
8. 客户端的 try/catch 大量吞异常，**报错只能靠 `elog` 通道看 message**

### 装备为什么"穿上不显示"

装备**不在** `2.props`，在角色自己的数据里：

```
1.roles.role0.cell = { "armL": "<propKey>", ... }   ← 已穿戴（槽位 → 道具 key）
1.roles.role0.bag  = { "<propKey>": {...} }         ← 该角色的装备背包
```

`2.props` 只装「全局背包 / 材料」。要真正给装备，得往 `roleN.bag` 塞带 `onlyKey` 的独立实例，
再把 key 写进 `roleN.cell`。堆叠形态（只有 `id`/`num`）能显示但穿不上。

### 技能等级必须 ≤ 配置数组长度

```

```

`effectValue[lv]` 是直接下标取值，给 `lv=100` 不报错但拿到 undefined → **技能伤害极低**。

### WC* 包在离线关卡里不生效（重要结论）

实测：进关后下发 `WCEnterLevel(1211)` 生成一只测试怪，客户端**不会出现**。
原因在 `world/game/Online.as`：

```as
if(!SceneManager.getInstance().currentGame.onlineActive) {
   backEvent[id].push(param1);   // 缓存

这些关卡的 `gameClass` 是 **`GameCopyPVP`**（服务端权威），`onlineActive` 为假，

1. AI 队友上阵（3 人同屏）
2. 服务端驱动怪物攻击

## 两个致命坑（都踩过）

**① `Python.start()` 必须在主线程**

放在后台线程会**原生层 abort**，Java 层看不到堆栈，只有：

```
libc++abi: terminating with uncaught exception std::system_error: mutex lock failed
libc: debuggerd signal invoked signal:6   → exit(1)
```

正确写法：`act.runOnUiThread(() -> { Python.start(new AndroidPlatform(ctx)); ... })`

**② 方法签名必须是 `Python.start(Python$Platform)`**

```smali
.method public static declared-synchronized start(Lcom/chaquo/python/Python$Platform;)V
```

写成 `AndroidPlatform` 参数会编译通过但运行时 `NoSuchMethodError`（服务端起不来 → 游戏报"获取服务器列表失败"）。
